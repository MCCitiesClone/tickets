# Slash commands

The bot registers these slash commands. "Who" describes who the command
effectively works for — some are gated in Discord by a default permission, and
several are additionally enforced in code (e.g. staff-only actions inside a
ticket). **Staff** means a member with a configured staff role or the Manage
Channels permission.

## Setup & info

| Command  | Options | Who            | Description                                                    |
| -------- | ------- | -------------- | ------------------------------------------------------------- |
| `/ping`  | —       | Everyone       | Confirms the bot is online.                                   |
| `/setup` | —       | Manage Server  | Links to this server's settings page in the dashboard.        |
| `/panel` | —       | Manage Server  | Links to the dashboard's panels page.                         |
| `/blacklist add\|remove\|list` | `target` — a user or role; `reason` — optional | Manage Server | Blocks or unblocks a user/role from opening tickets. See [blacklist](/docs/blacklist). |
| `/oncall list\|claim\|release\|add\|remove` | `note` — optional on `claim`; `user` — required on `add`/`remove` | Staff (`list`/`claim`/`release`), Manage Server (`add`/`remove`) | Manages who gets DMed when a ticket opens. See [on-call staff](/docs/on-call). |

## Working a ticket

Run these inside a ticket channel.

| Command                              | Options                                                                 | Who               | Description                                                             |
| ------------------------------------ | ----------------------------------------------------------------------- | ----------------- | ---------------------------------------------------------------------- |
| `/close [reason]`                    | `reason` — optional, saved to the transcript                            | Opener or staff   | Closes the ticket and posts a transcript.                              |
| `/closerequest [close_delay] [reason]` | `close_delay` — optional, 1–720 hours; `reason` — optional, ≤1000 chars | Ticket participants | Asks the opener to confirm closing, with an optional auto-close timer. |
| `/claim`                             | —                                                                       | Staff             | Assigns the ticket to you.                                             |
| `/unclaim`                           | —                                                                       | Staff / claimer   | Releases a claimed ticket.                                             |
| `/add <user>`                        | `user` — required                                                       | Ticket participants | Grants a member access to the ticket channel.                         |
| `/remove <user>`                     | `user` — required                                                       | Ticket participants | Revokes a member's access.                                            |
| `/rename <name>`                     | `name` — required, ≤80 chars                                            | Staff             | Renames the channel prefix, keeping the ticket number (e.g. `bug-42`). |
| `/priority [level]`                  | `level` — optional: Low, Normal, High, Urgent                            | Staff (set) / anyone (show) | Sets the ticket's triage priority, or shows it when `level` is omitted. |
| `/switchpanel <panel>`               | `panel` — required, autocompletes panel names                           | Staff             | Moves the ticket to another panel (category, naming, roles).           |
| `/notes`                             | —                                                                       | Staff             | Opens a private staff-only notes thread on the ticket.                 |
| `/cannedresponse <name>`             | `name` — required, autocompletes saved responses                        | Staff             | Posts a saved [canned response](/docs/canned-responses) into the channel. |

See the [ticket lifecycle](/docs/tickets) for how these fit together, and how
tickets also open and close from panel **buttons** rather than commands.

`/cannedresponse` also works outside tickets (any channel a staff member can
use it in) — see [canned responses](/docs/canned-responses).
